# Карта кампании Рина Вейра

Интерактивная карта перенесена из полного прототипа Хейвенгарда, включая исходный шаблон, схему и интерфейс редактирования планировки.

## Текущее состояние
Рин пока не владеет городом или поселением. Отсутствие `world.city` — подтверждённое состояние, а не ошибка и не повод автоматически создавать жителей, здания, доходы или казну.

- `map/layout-base.json` — базовый формат объектов и размещения.
- `map/template.html` — интерактивная оболочка карты.
- `map/offline.html` — автономная собранная версия.
- `tools/build_city_map.py` — сборка из `state/_campaign-state.json`.
- `tools/map_layout_import.py` — полный импорт пользовательской планировки.

Историческая Хейвенгардская карта и исходный генератор хранятся в `upstream_campaign/map` и `upstream_campaign/tools`. Их данные не смешивать с каноном Рина.

Любое реальное строительство, расход денег и изменение владений требуют подтверждённого события Campaign Engine. Файл карты — представление состояния, не второе сохранение.

**СПОЙЛЕРЫ:** основной репозиторий публичен; GM-планы и скрытые заметки обозначены отдельно, а не раскрываются Рину автоматически.
