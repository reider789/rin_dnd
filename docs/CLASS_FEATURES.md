# Классовые обработчики v30.3

Это контракт отдельных проверенных механизмов, а не автоматическое получение всех возможностей класса по его названию. Профиль задаёт `features`, персонаж — текущие `resources`. Уровень, экипировка и настройка предметов должны быть проверены адаптером кампании до создания профиля.

| Параметры профиля | Текущий ресурс | Команды и поведение |
| --- | --- | --- |
| `fighterLevel`, `secondWind`, `tacticalMind`, `tacticalShift` | `second_wind` | `secondWind`; разум предлагается после провала проверки с известной СЛ; сдвиг даёт отдельный маршрут |
| `actionSurge` | `action_surge` | `actionSurge`; дополнительное действие не оплачивает Магию |
| `fighterLevel`, `indomitable` | `indomitable` | Решение после провала спасброска, включая спасбросок от смерти |
| `knowEnemy` | `know_enemy`, при восстановлении `superiority` | `knowEnemy` по видимой цели в 30 футах; `restoreKnowEnemy` расходует кость без действия |
| `maneuvers`, `superiorityDie`, `maneuverDC` | `superiority` | Выбор при попадании, Точная атака после промаха, Ответный удар реакцией, `bait` при движении |
| `greatWeaponFighting`, `greatWeaponMaster`, `savageAttacker`, `tacticalMaster` | Ограничения на ход в сессии | Повторное применение не создаёт новый ход; Тактическое мастерство заменяет свойство оружия |
| `cunningAction`, `steadyAim`, `reliableTalent`, `uncannyDodge`, `evasion`, `sharpshooter` | Действия и реакция | Бонусное Скрытие/Рывок/Отход, `steadyAim`, проверки навыков, половина урона, этап урона от спасброска |
| `layOnHands` | `lay_on_hands` | `layOnHands` с `target`, целым `amount` либо `curePoison:true` |
| `auraProtection`, `auraRadius`, `auraDevotion`, `auraCourage`, `guardianSaveBonus` | Нет | Актуальное расстояние, стена и состояние владельца; одинаковые ауры не складываются |
| `protection`, `shieldEquipped` | Реакция | Выбор до броска атаки по соседнему союзнику; защита прерывается при разрыве дистанции |
| `shieldSpell`, необязательный `autoShield` | `shield_magic_initiate` либо `spell_slots` | Щит после попадания до урона; не отменяет натуральную 20; один расход ячейки за глобальный ход |
| `acReaction`, `critNegation` | `cloak_charges`, `guardian_mark` | КД на одну атаку либо отмена критического урона до броска костей |
| `heavyArmorReduction`, `heavyArmor` | Нет | Уменьшение физического урона атаки только при реально надетом тяжёлом доспехе |

Все счётчики имеют `{current,max}`. Неуказанный обязательный ресурс останавливает загрузку; движок не восстанавливает его по умолчанию. Наличие `channel_divinity`, `arcane_recovery` или другого зарегистрированного счётчика ещё не означает наличия обработчиков расходующих его способностей. Команды проходят `dispatch`; пользовательские решения содержат ID текущего окна.

Манёвры: `precision`, `trip`, `push`, `goad`, `maneuvering`, `riposte`, `bait`. Один манёвр на атаку. Кость добавляется к общему урону до уменьшений и сопротивлений. Маневрирующая атака расходует реакцию союзника и исключает атаки по возможности только от поражённого врага; передвижение от других существ разрешается обычным порядком. Приманка меняет местами двух согласных союзников; команда явно указывает `recipient` для бонуса КД. В нынешней кнопке интерфейса получатель — выбранный союзник.

NPC используют Второе дыхание по недостающим ПЗ, Всплеск после исчерпания обычных атак, защитные реакции по их условиям и Точную/Ответный удар. При попадании автоматический воин выбирает доступное Опрокидывание, толчок для дистанции либо провокацию при угрозе союзнику; не читает неизвестные спасброски цели. Маневрирующая атака и Приманка доступны игроку, но отдельная политика их планирования NPC ещё не реализована. Это ограниченные правила выбора, а не полный поиск последовательностей способностей.

Надёжный талант применяется к проверкам с объявленной профильной подготовкой. Тактическому разуму нужна определённая СЛ: общая команда Поиска пока её не задаёт и не предлагает этот выбор. `evasion` реализован в общей задаче `saveDamage` с `stat:DEX` и `halfOnSuccess`; его применение к конкретным новым заклинаниям проверяется при переносе этих заклинаний. Черты не добавляют автоматически очки характеристик: профиль уже содержит итоговые характеристики.

Сохранение классовой сессии использует оболочку v32 и содержит все незавершённые решения. Учебный пример — `examples/portable/class-defense-lab.json`. Ни этот пакет, ни тесты не изменяют канон Хейвенгарда или Рина.
