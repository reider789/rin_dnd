# Кампания Рина Вейра — Campaign Engine + тактический бой v29R

Этот репозиторий содержит **полноценную систему ведения кампании** на базе архитектуры Хейвенгарда, включая каноническое состояние, знания и память NPC, отношения, инвентарь, транзакции, летопись, время и игровые инструменты.

**Главные файлы:**
- [CAMPAIGN_ENGINE.md](CAMPAIGN_ENGINE.md) — как продолжать кампанию, сохранять ходы и запускать проверки
- [state/_campaign-state.json](state/_campaign-state.json) — единственное каноническое состояние
- [views/scene-context.md](views/scene-context.md) — последняя сцена и точка продолжения
- [rules/_campaign-rules.json](rules/_campaign-rules.json) — правила повествования и кампании
- [gm/README.md](gm/README.md) — **ВНИМАНИЕ, СПОЙЛЕРЫ ВЕДУЩЕГО**, неразыгранные планы не считаются каноном
- [upstream_campaign/](upstream_campaign/) — исходные инструменты Хейвенгарда для проверки и будущих расширений
- [map/offline.html](map/offline.html) — автономная карта/шаблон развития владений
- [index.html](index.html) — автономная тактическая игра Рина

Проверка: `python tools/run_tests.py`.
Источник истины — Campaign Engine; `config/rin_runtime.json` — производный снимок для **следующего**, ещё не начатого боя. Обновление данных не переписывает уже начатую боевую сессию.

## Исходная документация тактического боя


Самостоятельный боевой проект кампании Рина Вейра на **полной основе тактического интерфейса Хейвенгарда v29**. Исходная реализация сохранена в `upstream_snapshot/`, полный набор её модулей — в `core/`, исходный графический пакет — в `art/hayvengard_art_v1.json`.

## Запуск

Откройте **`index.html`** в браузере. Файл самодостаточен: содержит весь JavaScript, CSS, оригинальный графический пакет (4 фона, токены врагов/героев/препятствий) и индивидуальный круглый портрет Рина. Работа базовой карты и правил не требует сети.

**Важно:** встроенная «Засада у лесной дороги — учебный бой» — это **техническая реконструкция** уже завершённого эпизода. Её результаты **не попадают в летопись** и не переписывают состояние Рина автоматически.

### Сборка из исходников

```bash
python tools/adapt_engine.py
python tools/adapt_skin.py
python tools/build_rin.py
```

Сборщик формирует самодостаточный `index.html` и `rin-build-manifest.json`. Он соединяет исходный движок v29 с **неизменёнными** базовыми модулями боевой системы, оригинальным оформлением и новыми обработчиками классов Рина из `rin_rules.js`.

Для новой сцены подготовьте JSON по образцу `encounters/caravan_ambush_training.json`. В сборке можно выбрать другую сцену, заменив путь в последней строке `tools/build_rin.py` или вызвав функцию `build(scene=...)` из Python.

## Что сохранено из Хейвенгарда

- Оригинальная карта **11×8**, панели, очередь инициативы, карточки и подробный журнал.
- Все исходные модули: кости, состояния, поиск пути Дейкстры, коллизии, реакции, заклинания, сохранения, визуальные эффекты, несмертельные удары D&D 2024, подготовка отчёта для мастера.
- Полный визуальный стиль (бронза, дерево, фэнтезийная тактическая карта); три уровня анимаций.
- Сценарии с разными противниками, автоматические ходы NPC, отступления/пленение через правила конкретного боя.
- Сохранение/загрузка JSON, полный журнал, просмотр характеристик и инвентаря.

**Движок сохранён, но его обработчики не автоматически становятся применимыми к любому новому персонажу.** В интерфейс Рина выведены его фактические способности, а старые классовые способности Яра, Рады, Дафны и Лютобора не предлагаются игроку. Исторические обработчики остаются в коде для последующей адаптации других действующих лиц.

## Рин сейчас

**Разбойник 1 / Монах 3 (Воин Тени), D&D 2024**. 31 ПЗ, КД 16, скорость 40 футов, 3 максимальных очка фокуса. В сохранённом состоянии после засады фокус **0/3**; функция «Необычный метаболизм» может восстановить его один раз за долгий отдых на инициативе.

Оружие: короткий меч «Черта», кинжалы (Nick), короткий лук, безоружный бой. Реализована Скрытая атака 1к6, Vex, Nick, Шквал ударов с **отдельным выбором цели каждого удара**, Шаг ветра, Терпеливая защита, Отражение атак с возможностью перенаправления, магическая Тьма с концентрацией и перемещением, Малая иллюзия как заявляемое действие, Удача в атаке/защите, Необычный метаболизм. Нет Шага Тени и Дополнительной атаки — они не получены персонажем.

Часть нестандартных эффектов, включая **детальную трактовку иллюзии за пределами карты** и **переброс кости Героическим вдохновением**, требует ведущего; эти функции не следует считать полностью автоматизированными. Обработчики всех типов заклинаний из Хейвенгарда сохранены, но ещё не проверены для будущих новых NPC Рина.

## Канон и отчёт

Тренировочный бой не меняет основной Excel-файл. Для сюжетного боя используйте отдельный зафиксированный сценарий и после завершения сверяйте журнал, полученный урон, фокус, удачу, стрелы и исход. Исходные правила передачи мастеру остаются в `core/narrative_handoff.js`. Вне ChatGPT отчёт может требовать экспорта JSON.

`config/rin_runtime.json` — **снимок** данных Рина по текущему мастер-файлу (в отличие от постоянного онлайн-подключения). Перед следующим сюжетным боем обновляйте его из актуального листа; открытая игровая сессия не должна заменяться новым снимком без согласия игрока.
