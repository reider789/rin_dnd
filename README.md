# Рин Вейр — тактический боевой движок v29R

Полная адаптация боевого движка Хейвенгарда v29 для отдельной кампании Рина Вейра (D&D 2024).

Основная версия: `index.html`. Оригинальное ядро, графика, боевые правила, сценарии и тесты включаются в этот репозиторий.

Содержимое проекта публикуется из подтверждённого архива сборки. Канон кампании не изменяется учебными боями.
