# ⚠️ СПОЙЛЕРЫ ВЕДУЩЕГО: кампания Рина Вейра

Эта папка **публична** в GitHub по решению игрока. Здесь могут находиться нераскрытые сюжетные планы, тайны, мотивы NPC и варианты будущих сцен.

**Важное различие**: `candidate` означает *идею/подготовку*, а не уже случившийся факт; `canonical` — подтверждённый сыгранный факт. `gm` и `hidden_from_party` показывают, что персонаж игрока этого пока не знает. Доступность текста в публичном репозитории не меняет уровень знаний Рина.

Во время отыгрыша ведущий не должен раскрывать сведения только потому, что они здесь есть. Предложения будущих поворотов сверяются с уже сыгранным, а не насильно реализуются.

Актуальная точка продолжения — `views/scene-context.md`. Факты — `state/_campaign-state.json`, правила — `rules/_campaign-rules.json`.
